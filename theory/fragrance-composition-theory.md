# 香味调配理论（Fragrance Composition Theory）

本文件整理经典调香理论、分类图谱、与音乐编曲的类比，以及情绪映射的经验说法，供 AI 原生香蓄系统参考。

## 1. 香调金字塔（Fragrance Pyramid）

调香的最核心结构。根据挥发速度和持久度分层：

- **前调（Top Notes / Head Notes）**
  - 持续时间：约 5–30 分钟
  - 特点：最易挥发，第一印象
  - 常见成分：柠橘类（柠檬、伯格滴、柠橘）、薄荷、芳香草本、清新花香、青草
  - 作用：吸引注意力，开启香氛体验

- **中调（Heart / Middle Notes）**
  - 持续时间：约 30 分钟 – 4 小时
  - 特点：香氛的主体性格与灵魂
  - 常见成分：玫瑰、茉莉、白兰、伊兰、香料（肉桂、丁香）、果香、茶香
  - 作用：过渡前调与尾调，形成核心印象

- **尾调（Base Notes）**
  - 持续时间：数小时到一天以上
  - 特点：最持久，固定整体，增加深度
  - 常见成分：槀香、雪松、香草、磨香、珠珀、龙涎香、麋香、木质
  - 作用：提供持久度与体感，形成留香

**比例示例（简化）**：
- 前调 20%：柠檬 + 薄荷
- 中调 50%：玫瑰 + 茉莉 + 白兰
- 尾调 30%：槀香 + 香草 + 磨香

## 2. 香调轮（Fragrance Wheel）— Michael Edwards

全球最广泛使用的气味分类图谱，将香氛划分为四大主家族，再细分。

### 四大主家族
1. **Fresh（清新）**
   - Citrus（柠橘）、Water（水感）、Green（绿叶）、Aromatic（芳香草本）
2. **Floral（花香）**
   - Soft Floral、Floral、Floral Amber
3. **Oriental / Amber（东方/珀珀）**
   - Soft Oriental、Oriental、Woody Oriental
4. **Woody（木质）**
   - Woods、Mossy Woods、Dry Woods

**使用方式**：
- 相邻家族易于协调（清新 → 花香）
- 对角家族可形成对比与层次（柠橘 + 木质）
- 调香师常在轮上“漫游”找灵感

更多信息：https://en.wikipedia.org/wiki/Fragrance_wheel

## 3. 像写歌一样写香味

调香行业常用的比喻：

| 音乐元素       | 香味对应物                 | 说明                     |
|------------------|------------------------|--------------------------|
| 引子 / 开头     | 前调                   | 第一印象，吸引注意         |
| 主旋律           | 中调                   | 核心性格与叙事         |
| 和声与低音       | 尾调                   | 支撑、持久度与深度       |
| 配器与音量       | 不同香料的比例           | 控制强度与层次         |
| 曲式结构         | 时间线演变             | 前→中→尾的交叉淡入淡出     |
| 节奏与动态       | 喷洒时序与占空比       | 脉冲、突出某个调性       |

- 支持随机性与变奏（像 Agent 生成一样调整 temperature）
- 多通道硬件可实现真实的“演奏”

## 4. 情绪与香味的经验映射

**注意**：没有像色彩心理学那样严谨统一的科学图谱，以下为行业常见经验性说法，仅供参考。

- **活力 / 清新**：柠橘、薄荷、柠檬、芳香草本（迷迭香、迷叠香）
- **放松 / 平静**：薰衣草、甘菊、槀香、乳香、香草
- **温暖 / 安全**：香草、磨香、珠珀、软木质
- **力量 / 深沉**：槀香、雪松、皮革、柠橘木、龙涎
- **激昂 / 性感**：茉莉、伊兰、肉桂、玫瑰、某些辛香
- **清新活力**：青草、水感、生姜、柠橘

个体差异很大，受文化、记忆和生理影响。AI 系统建议提供“可调参”的情绪标签，而非硬编码。

## 5. 对 AI 原生香蓄系统的建议

- 用结构化 JSON 描述配方（通道、比例、时间线、淡入淡出）
- 支持随机性：在合理范围内变奏比例或时序
- 结合香调轮做约束（避免冲突家族混用）
- 多通道硬件 + Agent 生成配方 = 真正的“AI 原生香味作曲”
