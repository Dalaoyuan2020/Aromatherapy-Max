# Index（对话式 AI 香水机器）

**状态：** 真实商业 / 艺术项目（London，2025 成立）

**链接：**
- https://www.dazeddigital.com/beauty/article/71172/1/index-ai-machine-makes-perfumes-out-of-your-memories-fragrance-brand
- https://bricksmagazine.co.uk/2026/10/23/index-wants-you-to-smell-your-memories/

## 概述
用户描述一段记忆（3–5 分钟对话），AI Agent 分析后实时混合并滴入 6 ml 瓶子。

## 流程
- Agent 先识别叙事结构与情绪比例
- 再映射物理元素（海边、茶叶、皮肤温度等）
- 从 9 个预调基香（每个有完整前中尾调）中选 1–3 个并计算比例
- 实时混合交付

## 特点
- Agent 被赋予详细基香档案（香调、场景、情绪）
- 有明确规则：不简单关键词映射情绪
- 保存配方以便复购，对话本身不保留

## 评估
目前最接近「对话式 Agent → 实时硬件混合」的成熟案例之一。
